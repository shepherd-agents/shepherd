# Citation checker

The supported checker is the [Shepherd package](../../shepherd/extras/citation-checker/README.md).

```bash
shepherd-check-citations paper paper.pdf --output citation-report
```

See its [evaluation record](../../shepherd/extras/citation-checker/evaluation/README.md)
and [original candidate](../../shepherd/extras/citation-checker/docs/original-candidate/README.md).

The old runners, debugging scripts and intermediate reports in this directory
are ignored local exploration. They remain on disk when removed from Git tracking;
previously committed versions remain available in Git history. Active code and
regression tests do not import this tree.
